# Assets Images Directory

Taruh file logo Anda di folder ini dengan nama:
`logo.png` (ukuran disarankan 1024x1024 px PNG transparan atau persegi).

Setelah menaruh file `logo.png`, jalankan perintah berikut di terminal untuk memperbarui ikon aplikasi di Android & iOS:

```bash
dart run flutter_launcher_icons
```
